clauses hold and some do not; `unproven` = names the command or artefact that would prove it. **The

false for some rows and true for others, so it is replaced by the per-row fact rather than by a weaker
sentence.

**Which rows CI reaches, and the rule is mechanical.** A row's evidence runs in CI if and only if it
lives in one of the eight workspaces the table above lists as `yes`, or in a command the `checks` job

because none of them was ever a claim about CI, but the ground under them is now one machine wide.
Rows 0.1, 0.4, 0.5, 0.9, 0.12 and 0.13 are mixed and each says how.

**How these states were arrived at.** A passing suite proves the tests pass, not that they assert what
